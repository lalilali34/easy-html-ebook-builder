# pass9 · 费曼练习脚手架

## 本轮任务

为指定的子块生成**递进式费曼练习**：每一层给一个 `question` 和一个 `rubric`（自评清单）。
用户靠这套脚手架检验自己是否真的读懂了这一块，而不是"看懂字面"。

本步只生成**骨架**（问题 + 自评清单），不生成答案、不评分。

## 输入字段

- `global.core_problem` / `global.core_conclusion`：全文核心问题与结论
- `global.skeleton[]`：大块列表（`id` + `summary`），用于建立跨块对照
- `global.all_subblocks[]`：**全部**子块的 `id` / `function` / `summary`（已截断），用于指认具体块
- `batch[]`：本批要生成练习的子块 id 列表
- `batch_blocks[]`：本批子块的完整数据（`purpose` / `basis` / `key_points` / `author_says`）
- `depth`：生成到第几层（1–5），只生成 `level <= depth` 的层

## 输出格式

只输出 JSON，不输出任何解释：

```json
{
  "blocks": {
    "b1-1": [
      { "level": 1, "name": "复述", "question": "……", "rubric": "……" },
      { "level": 2, "name": "论证重构", "question": "……", "rubric": "……" }
    ]
  }
}
```

- 键必须是 `batch[]` 里真实存在的子块 id，一个都不能漏、不能多。
- `level` 从 1 连续递增到 `depth`。

## 五层定义（固定，不可改名）

| level | name | 考察什么 |
|---|---|---|
| 1 | 复述 | 能否用自己的话讲清这一块在说什么 |
| 2 | 论证重构 | 前提 → 结论的推理链；核心概念如何被使用与区分 |
| 3 | 举例/边界 | 正例、反例、极端情况；概念适用的边界在哪 |
| 4 | 连接 | 与本文其他块、与其他理论家/文本的对照 |
| 5 | 批判 | 作者未说清、可质疑之处；你的立场与理由 |

## question 的写法

要求：

1. **针对这一块的具体内容**，不能是通用模板句（「请复述这一块」这种不合格）。
2. 用第二人称直接问，一句话，不超过 80 字。
3. 一层只问一个焦点，不要在一个问题里塞三件事。
4. 允许结合 `key_points` / `author_says` 的具体内容，但不要直接把答案写进问题。

不合格（通用模板）：
> 请用你自己的话复述这一块的主要内容。

合格（针对本块）：
> 作者为什么说「同一把尺子衡量不同的人」反而制造了不平等？用自己的话讲清这个反常识的地方。

## rubric 的写法（人文社科向，3–5 条）

rubric 是**自评清单**，不是评分标准。写清楚"一个合格的答案应该包含什么"，让用户对着打勾。

每个 rubric 用 3–5 个短句，每条以「□」开头（渲染时会显示成勾选框样式），覆盖：

- **必须命中的要点**（漏了就算没读懂）
- **常见错误**（写成什么样说明跑偏了）
- **深度要求**（区分"复述"与"重构"）

### 各层的 rubric 重点

**L1 复述**
- 必须覆盖：这一块的核心命题
- 必须避免：直接抄原文句子
- 常见跑偏：把细节当主旨

**L2 论证重构**
- 必须覆盖：前提是什么、结论是什么、中间靠哪一步推过去
- 必须覆盖：核心概念在本文中的特定用法（不是字典义）
- 常见跑偏：把作者的结论当成前提

**L3 举例/边界**
- 必须覆盖：一个本文没写过的正例
- 必须覆盖：一个反例或极端情况
- 必须覆盖：概念在什么条件下失效
- 常见跑偏：例子太抽象、换汤不换药

**L4 连接**
- 必须覆盖：**具体的块 id**（如「与 b3-1 形成对照」）
- 必须覆盖：**具体的理论家或文本**（如「可对照布迪厄的场域」）
- 常见跑偏：写「与其他部分相互联系」这类空话

**L5 批判**
- 必须覆盖：作者一个真实的未说清之处
- 必须覆盖：你自己的立场 + 理由
- 常见跑偏：只指出"作者说得不够详细"，没有实质质疑

## L4 的硬性要求（重点）

L4 是全篇最容易被写成废话的一层。**必须**满足：

1. 引用 `global.skeleton` 或 `global.all_subblocks` 里**真实存在的块 id**；
2. 引用一个**具体的理论家姓名或著作名**；
3. 说明这个对照**具体在哪一点上成立**（不是"都属于结构主义"这种笼统归类）。

不合格：
> 这一块的内容与文章其他部分有联系，可以对照相关理论家的观点思考。

合格：
> 这一块对「同一尺度」的批评，和 b2-3 讲「形式平等掩盖结果不平等」是同一个论证动作；如果对照罗尔斯的「差别原则」，能看出两者对"什么算公平"的前提假设不同 —— 你认为哪个前提更站得住？

## 禁止事项

- 禁止编造 `global` 里不存在的块 id。
- 禁止编造理论家的观点或著作名；记不清就换一个你确定的理论家。
- 禁止在 question 或 rubric 里写出完整答案。
- 禁止所有层用同一个模板句式。
- 禁止输出 JSON 以外的任何文字。
