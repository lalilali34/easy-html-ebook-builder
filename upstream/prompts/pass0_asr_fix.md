# pass0 · ASR 错字修正

## 本轮任务

识别语音识别（ASR）造成的错字，输出**修正对照表**。本步只产出对照，不改写正文。

## 输入字段

- `text`：入库后的全文（可能来自字幕稿，存在同音/近音错字、专有名词错写、口语重复）

## 输出格式

只输出 JSON：

```json
{
  "corrections": [
    {
      "wrong": "王左",
      "right": "网左",
      "reason": "语境是网络左派，与文中「右翼」「政治光谱」对举",
      "confidence": "high"
    }
  ]
}
```

- `wrong` 必须是原文中**逐字出现**的字符串。
- `right` 是修正后的写法。
- `confidence` 只能是 `high` / `medium` / `low`。
- 没有发现错字时输出 `{"corrections": []}`。

## 判定标准（宁缺勿滥）

**只修「明显是转录错误」的词**，不要改作者的真实用词。

**6. `wrong` 只填错字本身（通常 2–6 字），不要把整句或短语片段写进去。**
例：写 `拿下大卫`，不要写 `特朗普拿下大卫开始执政`；写 `东东`，不要写 `东东根本不是核心利益`。
原因：替换是按 `wrong` 原文精确匹配，片段越长越容易和原文对不上（标点、空格差异都会导致替换失败）。

可以修正的类型：

1. **同音/近音错字**：`等家交换`→`等价交换`、`权力原则`→`权利原则`、`隔达钢领批判`→`哥达纲领批判`
2. **专有名词错写**：人名、书名、机构名被转录成同音字
3. **网络/学术黑话的转录错误**：`王左`→`网左`、`目田`→`自由`
4. **明显的口语重复残留**：`然后然后`→`然后`（仅当确实是重复而非修辞）
5. **术语首次出现时的错写**：后续出现正确写法，可据此反推

**禁止修正的类型**：

- 作者刻意使用的方言词、口语表达
- 正常的中文词汇（即便你觉得"不够学术"）
- 人名书名，除非你**确定**是转录错误（不确定就跳过）
- 句子结构、语序、标点（本步只做词级替换）

## confidence 定义

| 值 | 含义 | 是否自动应用 |
|---|---|---|
| `high` | 读了上下文后确定是错字，且有明确正确写法 | ✅ 自动替换 |
| `medium` | 很可能是错字，但正确写法有多个候选 | ❌ 只记录，人工确认 |
| `low` | 可疑但不确定 | ❌ 只记录 |

**拿不准的一律给 medium 或跳过，不要给 high。**

## 数量控制

- 一篇 1 万字的稿子，通常 5–30 条。
- 如果给出超过 60 条，说明判定过宽——请自己收紧标准，只保留最确定的。

## 禁止事项

- 禁止输出 JSON 以外的任何文字。
- 禁止给出 `wrong` 不在原文中的条目（会被直接丢弃）。
- 禁止把整句重写塞进 `right`（只做词级替换）。
