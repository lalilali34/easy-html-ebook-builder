# pass5 · 作者说 / 我的层次（两阶段）

## 本轮任务

分成两个阶段，**确认前一阶段合规后才做后一阶段**：

- 阶段 A：只输出 `author_says`——作者在这块里到底说了什么，逐条带原文引用或时间戳。
- 阶段 B：才输出 `my_inferences` / `my_examples` / `my_questions`——我的推断、我的例子、我的疑问。

## 输入字段

- `blocks[]`：pass4 的块（含 `purpose` / `basis` / `depends_on` / `key_points`）。
- `segments[]`：原文段落，用于逐字摘 `quote` 和定位 `timestamp`。

## 阶段 A 输出字段

```json
{
  "author_says": {
    "b1": [
      { "text": "对作者这句的转述", "quote": "原文逐字引用", "timestamp": 2.6 }
    ]
  }
}
```

- 每条至少带 `quote` 或 `timestamp` 之一；能从原文逐字摘就同时给。
- `quote` 必须与输入 `segments[].text` 逐字一致。
- `text` 是转述，可以概括，但不得在转述里掺入作者没说的判断。

## 阶段 B 输出字段

```json
{
  "my_layer": {
    "b1": {
      "my_inferences": [
        { "kind": "core",     "claim": "作者这一步的真实意图是什么" },
        { "kind": "forward",  "claim": "如果这个推论成立，还能推出什么（要写清从 A 到 B 的链条）" },
        { "kind": "forward",  "claim": "第二条正向外延" },
        { "kind": "backward", "claim": "如果反过来，哪一部分会塌（要写清矛盾点）" },
        { "kind": "backward", "claim": "第二条反向外延" },
        { "kind": "boundary", "claim": "这个推论在什么条件下失效（可选）" },
        { "kind": "rival",    "claim": "还有别的读法吗，区别在哪（可选）" },
        { "kind": "test",     "claim": "怎么验证它站得住（可选）" }
      ],
      "my_examples": ["我自己补充的例子"],
      "my_questions": ["我仍然存疑的地方"]
    }
  }
}
```

### 硬性数量要求

| kind | 数量 | 必填 |
|---|---|---|
| `core` | **恰好 1** | ✅ |
| `forward` | **恰好 2** | ✅ |
| `backward` | **恰好 2** | ✅ |
| `boundary` | 0 或 1 | ❌ 可选 |
| `rival` | 0 或 1 | ❌ 可选 |
| `test` | 0 或 1 | ❌ 可选 |

**可选三项（boundary / rival / test）宁缺勿滥**：只在确实有内容可写时输出。
写不出就不写这个对象，**不要为了凑数编一句通用的话**。

### 各 kind 的写法要求

**`core`**：作者没说但意图明显的判断。句式是「作者这样写，是为了……」「这意味着……」。

**`forward`**：从核心推论往下推一步，要带链条——
「若 A 成立，那么本文第 X 处也应该如此（而它确实如此）」，或「若 A 成立，读者容易把 B 与 C 混为一谈」。
禁止写成同义反复（「这说明作者很重视这个概念」这种没有推力的句子）。

**`backward`**：假设核心推论不成立，指出**哪一部分会自相矛盾**，并说明作者实际上是怎么做的。
句式是「若不……，则……就讲不通，但作者明说/明明……」。要指向具体内容，不能空泛。

**`boundary`**：这个推论依赖什么前提，前提不成立时会怎样。要具体到某个条件。

**`rival`**：给出另一种同样说得通的读法，并指出**两种读法的分歧点在哪**（不是「也有人认为……」）。

**`test`**：给出一个可在本文内部核对的检验点——「看作者在 X 处是否 Y」。

### my_examples / my_questions 必须挂靠推论

这两个字段**不能独立发挥**，必须指向本块 `my_inferences` 里的某一条。

**`my_examples`（每条检验一条 `forward`）**

写法：「（对应正向外延①）我想到……」

要求：
- 例子要回答「如果这条外延成立，现实里应该能看到什么现象」
- 优先举本文没写、但符合同一机制的实例
- 每条例子必须能对应到某一号正向外延；对应不上的例子不要写
- 禁止写"这让我联想到……"这种与推论无关的泛泛类比

**`my_questions`（每条针对一条 `backward` 或 `boundary`）**

写法：「（对应反向外延②）……」

要求：
- 问题要指向推论的可疑点：这条推论在什么情况下不成立？作者为什么要回避某个结论？
- 禁止问「作者是什么意思」「这个概念的准确含义」这类复述性、定义性问题
- 禁止问与推论无关的背景知识问题

**示例（合格）**：
- 例子：「（对应正向外延①）我想到同一个小区里，租房的和业主对"物业费涨价"的态度完全不同——按人头均摊看似公平，实际负担却因产权状态而分化。」
- 疑问：「（对应反向外延②）如果法权随法律废除而消失，那作者为什么强调它在共产主义第一阶段"仍然存在"？这里的"存在"是指制度事实还是分析范畴？」

**示例（不合格）**：
- 例子：「我把它类比为公司的考勤制度。」（没有说明检验哪条外延，也没有揭示机制）
- 疑问：「法权到底是什么？」（复述性提问，不是对推论的质疑）

### self_reflection（AI 自我反思，可选）

只评**你自己**这一块的处理，不重复 evaluation 里对作者的批评。

要写「哪里站得住、哪里需要补什么」，像同事之间互评：

- 合格：「本块对"形式/内容"的区分站得住，但若要更严谨，需要补证作者说"内容已变"时依据的历史文献。」
- 合格：「推论链成立，但 b2-3 的引文只到"同一原则"为止，后半句是我补的，严格说超出了原文。」
- 合格：「这里我把作者的类比展开了三层，第三层是我加的，原文只到第二层。」
- 不合格：「本块分析得比较全面。」（没有指出任何具体问题，等于没写）
- 不合格：「我认为作者说得对。」（立场表态，不是自我诊断）

**与 evaluation 的分工**：evaluation 说「作者哪里有问题」，self_reflection 说「**我自己的处理**哪里有问题」。
两者不能写同一件事。

**确实没有问题可指**时，就不输出这个字段，不要硬凑。

### evaluation（原文质量评估，可选，AI 自选适用维度）

对**这一块的原文（作者）质量**打分。**不是**评你自己的分析，也不是评转述准确与否。
只输出与这一块内容相关的维度；不相关的直接不写。

**关键**：`note` 的主语必须是「作者」，且**不能出现「转述」「我的分析」这类指代你自己动作的词**。
直接陈述作者的问题，不要绕一层。

**示例（合格）**：
- `{ "dim": "textual_fidelity", "score": "良好", "note": "引用《哥达纲领批判》基本忠实，但略去了「资产阶级权利」的限定条件" }`
- `{ "dim": "conceptual_clarity", "score": "一般", "note": "作者把「等价交换」与「按劳分配」混用，未区分交换与分配两个领域" }`
- `{ "dim": "dialectical_depth", "score": "一般", "note": "只讲资产阶级法权的消极面，未提它相对封建特权的历史进步性" }`
- `{ "dim": "ideological_stance", "score": "良好", "note": "明显倾向马克思主义分析，对西方经济学只作否定性提及" }`

**示例（不合格）**：
- `{ "note": "作者对「权利原则」的表述被转述为「权力原则」" }` ← 绕了转述这一层，而且是在说你的转述
- `{ "note": "转述将「权利原则」写成「权力原则」" }` ← 完全在评自己
- `{ "note": "分析得比较全面" }` ← 没有指向任何具体问题

- `score` 只能是 `优秀` / `良好` / `一般` / `存疑`。
- `note` 一句话说明依据（40 字以内），主语是作者。
- **通常一块只看 2–4 个维度**；不适用就不写，不要凑满七项。

| dim | 中文 | 何时适用 | 评作者什么 |
|---|---|---|---|
| `textual_fidelity` | 文本忠实度 | 作者引用了他人文献/观点时 | 作者对其引用文献的转述是否准确，有无望文生义、断章取义 |
| `conceptual_clarity` | 概念辨析 | 出现抽象概念时 | 作者是否严格区分了易混概念（形式/内容、权利/权力、等价交换/按劳分配） |
| `historical_accuracy` | 历史语境 | 涉及历史事件/时期时 | 作者的史实陈述是否准确，有无时代错置 |
| `dialectical_depth` | 辩证深度 | 文本有正反两面时 | 作者是否呈现矛盾双方，还是只做单边陈述 |
| `falsifiability` | 可证伪性 | 有明确论断时 | 作者的论断是否给出可检验的条件、时间或情境 |
| `ideological_stance` | 立场预设 | 文本有立场性时 | 作者站在什么立场（客观评述 / 马克思主义分析 / 西方经济学分析等），用中性描述 |
| `explanatory_power` | 解释力 | 有解释性论断时 | 作者的解释能否覆盖文中的复杂现象，还是显得牵强 |

- `score` 只能是 `优秀` / `良好` / `一般` / `存疑`。
- `note` 一句话说明依据（40 字以内），主语是作者。
- **通常一块只看 2–4 个维度**；不适用就不写，不要凑满七项。

**示例（合格）**：
- `{ "dim": "textual_fidelity", "score": "良好", "note": "引用《哥达纲领批判》基本忠实，但略去了「资产阶级权利」的限定条件" }`
- `{ "dim": "conceptual_clarity", "score": "一般", "note": "作者把「等价交换」与「按劳分配」混用，未区分交换与分配两个领域" }`
- `{ "dim": "dialectical_depth", "score": "一般", "note": "只讲资产阶级法权的消极面，未提它相对封建特权的历史进步性" }`
- `{ "dim": "ideological_stance", "score": "良好", "note": "明显倾向马克思主义分析，对西方经济学只作否定性提及" }`

**示例（不合格）**：
- `{ "note": "转述将「权利原则」写成「权力原则」" }` ← 这是评你自己的转述，不是评作者
- `{ "note": "分析得比较全面" }` ← 没有指向任何具体问题

## 禁止事项

- `author_says` 的 `quote` 必须逐字取自 `cleaned.jsonl`，不得使用 pass1 或任何前序轮的 ASR 还原词。
- my_inferences 不得复述 author_says 的 text 转述句；推断必须包含原文没有直接说出的判断（如“作者这样写是为了……”“这意味着……”），不能只是把转述句换个说法。
- 禁止把推断写进 `author_says`，禁止把作者原话写进 `my_inferences`。
- 禁止在没有 `quote` 或 `timestamp` 的情况下凭空写 `author_says`。
- 禁止在阶段 A 里顺手输出 `my_*`（阶段边界，确认后才做 B）。
- 禁止跨块复制同一句引用（同一作者原话只出现在它实际所在的块）。
- 禁止输出 JSON 以外的任何文字。
